APRS Digipeater Dashboard

Full history, charts, DX rankings, and messaging for your APRS digipeater. Pick your operating system and download — no Python or anything else to install.

Windows
.exe — double-click to open
macOS
.zip — Intel and Apple Silicon
Linux
.zip — generic x86_64 binary

How to use after downloading

  1. Download the file for your system above. macOS and Linux come as a .zip — unzip it first (most browsers do this automatically; otherwise double-click the .zip).
  2. Windows: the app isn't code-signed yet, so a SmartScreen warning will appear — click "More info" → "Run anyway" (this is expected, not a sign of a problem). macOS: the app is signed with an Apple Developer ID certificate and notarized, so it should just open normally the first time — you may see a one-time "downloaded from the internet" prompt, just click Open. If Gatekeeper still blocks it for any reason, right-click the unzipped file → Open, or go to System Settings → Privacy & Security and click "Open Anyway". Linux: open a terminal in the unzipped folder and run chmod +x aprs_dashboard-linux then ./aprs_dashboard-linux.
  3. Your browser opens automatically at http://localhost:8080. Windows and macOS: no terminal window — the app keeps running quietly in the system tray / menu bar (look for its icon there); right-click it to reopen the dashboard or quit. Linux: it runs in the terminal window you opened — leave it open, and close it (or Ctrl+C) to stop the server.
  4. In the dashboard's Settings tab, fill in the IP address and ports of YOUR digipeater on your local network.
