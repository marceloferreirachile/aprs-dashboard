Como usar depois de baixar

  1. Baixe o arquivo do seu sistema acima.
  2. Windows: se aparecer aviso do SmartScreen, clique em "Mais informações" → "Executar assim mesmo" (é normal pra executáveis sem certificado pago). macOS: clique com o botão direito no arquivo → Abrir (na primeira vez, pra passar do Gatekeeper). Linux: chmod +x aprs_dashboard-linux e depois ./aprs_dashboard-linux.
  3. O programa abre uma janela de terminal (deixe aberta — é o servidor rodando) e o navegador abre sozinho em http://localhost:8080.
  4. Na aba Configurações do dashboard, preencha o IP e as portas do SEU digipeater na sua rede local.
